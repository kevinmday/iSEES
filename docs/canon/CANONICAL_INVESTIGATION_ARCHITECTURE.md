// INVESTIGATION MANIFOLD CANON

// ============================================================

//

// PRINCIPLE

//

// The Investigation Manifold is the sole deterministic

// representation of the current investigation state.

//

// All computation produces an Investigation Manifold.

//

// No visualization owns deterministic investigation state.

//

// Every visualization is a projection derived from the

// Investigation Manifold.

//

// ============================================================

//

// CANONICAL PIPELINE

//

//                  OPERATOR

//                      │

//                      ▼

//              Investigation Workspace

//                      │

//        Active Investigation Layers

//                      │

//                      ▼

//      Resolve–Dissolve Computation (RDC)

//                      │

//                      ▼

//          Investigation Manifold

//                      │

//      Complete Deterministic State

//                      │

//      ┌─────────┬─────────┬─────────┬─────────┐

//      ▼         ▼         ▼         ▼

//    Graph   Timeline Narrative Intention

//      ▼         ▼         ▼         ▼

//   Evidence  Playback Diagnostics Research

//

// ============================================================

//

// WORKSPACE

//

// The Workspace owns:

//

// • Active Investigation

// • Imported Events

// • Operator Modes

// • Active Investigation Layers

// • Selected Artifacts

// • Focused Event

//

// The Workspace never performs computation.

//

// ============================================================

//

// INVESTIGATION LAYERS

//

// Investigation Layers describe dimensions of reality.

//

// Examples:

//

// • Narrative

// • Observability

// • Infrastructure

// • Geographic

// • Temporal

// • Topology

// • Electromagnetic

// • Intention

// • Political

// • Economic

//

// Layers are computational inputs.

//

// Layers never belong to any visualization.

//

// ============================================================

//

// RESOLVE–DISSOLVE COMPUTATION

//

// RDC consumes:

//

// • Workspace

// • Active Layers

//

// RDC deterministically computes:

//

// • Investigation Manifold

//

// RDC never performs rendering.

//

// ============================================================

//

// INVESTIGATION MANIFOLD

//

// The Investigation Manifold represents the complete,

// deterministic state of the investigation.

//

// Examples:

//

// • Events

// • Actors

// • Facilities

// • Observations

// • Artifacts

// • Hypotheses

// • Relationships

// • Topology Metrics

// • Contradiction Metrics

// • Confidence Metrics

// • Intention Metrics

// • History

// • Residual Instability

// • Cluster Structure

//

// The Investigation Manifold contains no rendering

// information.

//

// It contains:

//

// • no SVG

// • no x/y coordinates

// • no colors

// • no icons

// • no layout

//

// ============================================================

//

// PROJECTIONS

//

// Projections are visual interpretations of the

// Investigation Manifold.

//

// Examples:

//

// ProjectionGraph(manifold)

//

// ProjectionTimeline(manifold)

//

// ProjectionNarrative(manifold)

//

// ProjectionEvidence(manifold)

//

// ProjectionIntention(manifold)

//

// ProjectionPlayback(manifold)

//

// Every projection consumes the same deterministic

// Investigation Manifold.

//

// No projection performs deterministic computation.

//

// ============================================================

//

// CANONICAL LAW

//

// Layers influence the Investigation Manifold.

//

// The Investigation Manifold is the sole deterministic

// investigation state.

//

// Every visualization is a projection of the

// Investigation Manifold.

//

// No visualization owns deterministic investigation state.

//
