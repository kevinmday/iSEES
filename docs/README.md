# iSEES Documentation

This directory contains the canonical documentation for the iSEES platform.

## Structure

architecture/
    System architecture and subsystem specifications.

design/
    Operator Experience (OX) design system.

decisions/
    Architecture Decision Records (ADR).

whitepapers/
    Formal technical papers describing iSEES methodologies.

roadmap/
    Engineering milestones and future planning.

research/
    Supporting investigations and notes.
