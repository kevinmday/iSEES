# ============================================================

## Abstract

Resolve–Dissolve Computation (RDC) is the foundational computational
architecture of iSEES.

RDC defines the computational universe in which every investigation is
performed.

Unlike traditional analytical systems, RDC does not simply reveal or
hide existing information.

Instead, RDC reconstructs the Investigation Manifold by deterministically
recomputing the mathematical relationships produced by the currently
selected investigative assumptions.

Every modification to the computational universe produces a new
deterministic topology.

The Investigation Manifold is therefore not merely a visualization of
stored knowledge.

It is the computational product of the active computational universe.

Every resulting topology is deterministic.

Every execution is reproducible.

Every computation is inspectable.

No hidden reasoning exists.

---

# 1. Motivation

Traditional analytical systems employ static datasets and visualization
layers.

Layers generally affect presentation only.

Enabling or disabling a visualization layer merely changes what the
operator sees.

The underlying mathematical relationships remain unchanged.

RDC rejects this architectural model.

Within iSEES, computational layers participate directly in the
construction of the Investigation Manifold.

Changing the computational universe changes the mathematics.

Changing the mathematics changes the topology.

Changing the topology changes the investigative conclusions.

The investigation therefore evolves not because the visualization has
changed, but because the mathematical universe being computed has
changed.

This distinction is the defining architectural principle of
Resolve–Dissolve Computation.

---

# 2. Governing Principle

Resolve–Dissolve Computation is founded upon one governing principle.

> Every change to the computational universe requires complete
> deterministic recomputation of the Investigation Manifold.

Nothing is merely hidden.

Nothing is merely revealed.

The Investigation Manifold itself changes.

Every topology is therefore the deterministic consequence of the active
computational assumptions.

# 4. Computational Universe

The computational universe is defined by three independent dimensions.

• Active Computational Layers

• Temporal Context

• Investigative Scale

Together these define the complete mathematical environment within which
an investigation is executed.

Changing any component of the computational universe requires complete
deterministic recomputation.

Incremental topology updates are intentionally prohibited.

The Investigation Manifold is always computed as a complete mathematical
solution rather than as a collection of partially updated graph
structures.

---

# 5. Resolve

Resolve represents the deterministic introduction of computational
information into the active computational universe.

Resolve does not merely add data.

Resolve expands the mathematical solution space from which the
Investigation Manifold is constructed.

Examples include

• enabling additional computational layers

• enabling computational layer groups

• importing investigations

• importing knowledge objects

• enabling research profiles

• expanding temporal context

• increasing investigative scale

• introducing additional observational evidence

Every Resolve operation increases the computational universe available
to deterministic computation.

No conclusions are generated during Resolve itself.

Resolve only modifies the computational assumptions.

---

# 6. Dissolve

Dissolve represents the deterministic removal of computational
information from the active computational universe.

Dissolve intentionally reduces the mathematical solution space.

Examples include

• disabling computational layers

• disabling layer groups

• removing investigations

• excluding observations

• reducing investigative scale

• restricting temporal context

• removing computational assumptions

Like Resolve, Dissolve performs no reasoning.

Its purpose is to redefine the computational universe prior to
recomputation.
